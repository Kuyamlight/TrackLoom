# WASAPI playback evidence

This directory holds manually completed WASAPI playback evidence only. Do not
create a run record until a user has chosen the output device and completed the
600-second listening check. Automated CTest can only report the hardware runner
as designed skip when it is not explicitly enabled.

Copy `run-template.md` to a new file named with an absolute date, for example
`2026-08-13-wasapi-playback.md`, and complete every field from the runner log
and the listening session. The evidence commit must be recorded before the run.
